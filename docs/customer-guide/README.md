# PeopleOS customer guide

The customer guide for **Markedge PeopleOS**, chapter by chapter. The same content, with a cover, contents and page
numbers, is in the [Customer Handbook (PDF)](../handbook/PeopleOS-Customer-Handbook.pdf) and the
[HTML handbook](../handbook/PeopleOS-Customer-Handbook.html).

Every screenshot is a genuine capture of the application in a demonstration environment with fictional people and
companies. Commercial terms (prices, plans, service levels, hosting) are not part of the product and are marked
**"To be confirmed with the SaaS provider."**
