# 5. Module guides

> **In this chapter:** the map of every PeopleOS module and the nine module chapters that explain them step by step.
> **Who should read it:** everyone looking for a specific screen or task.

PeopleOS has **195 modules** (screens) that a customer organisation can use. They are grouped into nine module chapters:

| Chapter | Covers | Read it if you are… |
|---|---|---|
| [5.1 Your workspace](modules/01-workspace-and-self-service.md) | Signing in, Home, search, My work, approvals, tasks, notifications, personal pages | everyone |
| [5.2 People and lifecycle](modules/02-people-and-employee-lifecycle.md) | Directory, Employee 360, hiring, imports, documents, background checks, onboarding, letters, exit, settlement, alumni | HR, managers |
| [5.3 Time and leave](modules/03-time-and-leave.md) | Attendance, punches, devices, shifts, schedules, holidays, regularisation, overtime, leave, balances, encashment | everyone, HR, managers |
| [5.4 Pay](modules/04-payroll-compensation-and-compliance.md) | Payroll, payslips, salary components and structures, tax declarations, statutory compliance, compensation | payroll, HR, employees (payslips) |
| [5.5 Growth](modules/05-performance-learning-and-talent.md) | Performance, goals, feedback, one-on-ones, calibration, learning, skills, development, career, talent, succession | everyone, managers, HR |
| [5.6 Organisation](modules/06-organisation-workforce-and-assets.md) | Legal entities, companies, departments, locations, establishments, people set-up data, org map, workforce planning, assets | administrators, HR, executives |
| [5.7 Services and communication](modules/07-services-and-communication.md) | My HR, HR service desk, grievances, knowledge base, announcements, notifications, surveys, feedback | everyone, HR |
| [5.8 Insights](modules/08-insights-analytics-and-ai.md) | Command centre, analytics, reports, dashboards, audit trail, change intelligence, AI assistance | executives, HR, auditors |
| [5.9 Administration](modules/09-administration-and-security.md) | Users, roles, settings, feature flags, custom fields, forms, workflows, policies, security, single sign-on, API, integrations, data export | administrators |

### Modules with a personal name

Seven modules change their name and content for employees, who see only their own records:

| Staff name (HR, administrators) | Employee name (own records only) | Where employees find it |
|---|---|---|
| Services › Service Desk › HR queue | **My requests** | Services › My HR › Requests, or search |
| Services › Grievances › Cases | **My grievances** | search "My grievances" |
| Services › Knowledge › Articles | **Knowledge base** | search "Knowledge base", or My HR › Policies |

| People › Lifecycle › Exit cases | **My exit** | search "My exit" |
| Organisation › Assets › Asset register | **My assets** | Organisation › Assets |
| People › Growth › Enrolments | **My learning** (enrolments) | People › Growth, or avatar › My learning |

## Module directory

Every module below was confirmed in the application. The menu path is the usual one; modules used less often are listed
under **All in [area]** on the area bar of that area, and any module can be opened by typing its name in the search bar
(**Ctrl K**). *Who can open it* lists the ready-made roles whose permissions open the module (the **Tenant Super Admin**
can open every module and is not repeated). Opening a module does not always allow changing it; the module chapters
explain which actions each role can take.
