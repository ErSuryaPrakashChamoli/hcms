# PeopleOS customer implementation checklist

**For:** the customer implementation team and the Markedge implementation lead. The editable workbook is `PeopleOS-Customer-Implementation-Checklist.xlsx` (status drop-downs); this page is a read-only copy.

Menu paths are real (training environment, 21 October 2026, commit `72c96a73`). **Mode** shows whether a stage is configured in PeopleOS, done by a Markedge operator, automated, manual outside PeopleOS, or blocked. Release gate: **NO-GO** (10 of 14 gates blocked, re-verified 13 October 2026).
